## Why a Blog

I've always wanted a space of my own — somewhere to record thoughts and share what I've learned. Not the fragmented expression of social media, but a place where I can write slowly and think deeply.

## This Website

This site started as a simple portfolio and gradually evolved into what you see now. Built with React + Vite + Tailwind, deployed on GitHub Pages. The design aims for a clean yet textured feel — dark theme, glassmorphism, smooth animations.
